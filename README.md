# scriptdonettaky-notes

Go · Observability · Python

学习用的示例项目

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/scriptdonettaky-notes.git
cd scriptdonettaky-notes
cargo build --release
```
